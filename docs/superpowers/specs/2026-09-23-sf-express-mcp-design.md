# 顺丰下单与查件 MCP 服务设计

## 目标

在当前空目录建立独立的 Python MCP 服务，让 AI Agent 调用两个面向顺丰速运普通寄件的工具：创建订单和查询物流轨迹。第一阶段以沙盒和本地模拟测试验收；取得本账号的顺丰凭据及最新接口说明后再联调。顺丰同城、顺丰国际、面单打印、退货和批量下单不在本期范围。

## 已核对的平台能力

- 顺丰开放平台提供 API 客户接入及沙盒联调。[平台首页](https://open.sf-express.com/)
- 公开的顺丰接口规范列出 `EXP_RECE_CREATE_ORDER`、`EXP_RECE_SEARCH_ROUTES` 和订单结果查询 `EXP_RECE_SEARCH_ORDER_RESP`。该规范标注于 2019 年，因此生产接入前须与账号下的当前文档核对。[接口规范](https://qiao.sf-express.com/doc/download/%E4%B8%B0%E6%A1%A5%E5%B9%B3%E5%8F%B0%E6%96%B0API%E6%8E%A5%E5%8F%A3%E8%A7%84%E8%8C%83.pdf)
- 公开的官方 SDK 指南列出 `partnerID`、`requestID`、`serviceCode`、`timestamp`、`msgData`、`msgDigest`，以及顾客编码和校验码的用途。[SDK 指南](https://qiao.sf-express.com/doc/download/laas/sdk/%E4%B8%B0%E6%A1%A5SF-CSIM-EXPRESS-SDK%E6%8C%87%E5%8D%97.pdf)

## 方案选择

采用独立 Python MCP stdio 服务。顺丰请求、签名、响应解析和业务校验全部在服务内完成。相比通用 HTTP 工具，这样 Agent 不接触密钥和签名细节；相比依托现有后端，当前空目录不需要额外服务。

## 组件

1. **MCP 工具层**：声明输入与输出，向 Agent 提供 `sf_create_order` 和 `sf_track_shipment`。
2. **业务校验层**：校验订单号、联系人、电话、地址、托寄物及查询号，构造顺丰请求。暂只支持中国内地普通寄件，其他场景给出明确的“不支持”错误。
3. **顺丰客户端**：从环境变量读取顾客编码、校验码、环境及超时；构造请求 ID、时间戳和签名；以表单 POST 调用沙盒或生产地址；解析平台结果和业务结果。所有地址与签名算法以当前账号文档最终核对。
4. **响应映射**：把顺丰字段转换为稳定的工具结果，保留可诊断的错误代码，不返回密钥或完整原始报文。

## 工具契约

### `sf_create_order`

输入：调用方提供唯一且稳定的 `order_id`、寄件人及收件人的姓名、电话和完整地址、至少一个托寄物名称；可选包裹数、重量、快递产品、付款方式、预约揽收时间和备注。MCP 描述应说明这是会创建真实订单的操作，调用 Agent 必须先展示订单摘要并取得用户确认。服务默认沙盒；生产请求还需显式启用生产配置。

输出：`order_id`、顺丰运单号列表、订单处理状态，以及必要的错误代码与说明。只有平台层和业务层均成功才报告成功。若请求超时或连接中断，先按同一 `order_id` 调用订单结果查询；仍无法确认时返回 `outcome_unknown`，不自动重复下单。

### `sf_track_shipment`

输入：`tracking_type` 为 `waybill` 或 `order`，以及对应的一个查询号。顺丰接口按运单号或本接入方订单号查询，查询结果受账号归属限制。

输出：查询号、运单号（若返回）、最新轨迹节点、按时间排序的轨迹数组和查询时间。轨迹节点包含时间、地点、描述和操作码；无轨迹时返回空数组及明确状态。该工具不把“订单结果查询”误当作“物流轨迹查询”。

## 安全与错误处理

- `partnerID` 和 `checkWord` 只从环境变量读取，不放入 MCP 参数、版本库、输出或日志。
- 错误区分输入校验、鉴权或权限、平台限流、业务拒绝、网络失败和结果不确定；不向 Agent 返回寄收件人的完整电话和地址。
- `order_id` 由调用方稳定提供，作为重复请求与超时核查依据。MCP 主机的工具批准机制承担实际的人类确认；工具说明和生产开关作为附加保护。
- 默认沙盒，生产环境需明确配置；不会在缺少凭据时向顺丰发请求。

## 验证

- 单元测试覆盖签名、请求封装、字段校验和响应解析。
- 模拟顺丰响应验证下单成功、业务失败、平台失败、轨迹为空及网络超时后的订单结果核查。
- 凭据就绪后，在沙盒创建测试订单并用返回的运单号查询轨迹；上线前对照当前账号文档复核字段、签名、服务授权与沙盒/生产地址。
